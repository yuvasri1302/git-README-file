# ToyJoy: Retail Inventory Management & Sales Performance Analysis

A retail inventory and sales analysis project for ToyJoy, a toy company managing products across multiple warehouses and suppliers. The project uses Power BI to monitor stock, identify sales trends, and support better inventory decisions.

## Objectives

- Track inventory levels and inventory value
- Identify top-selling products and categories
- Compare stock across warehouses
- Flag products that need reordering
- Reduce stock shortages and excess inventory

## Dataset

The dataset includes product ID and name, category, supplier, warehouse, stock quantity, unit price, reorder level, units sold last month, and product rating.

## Dashboard Features

- Inventory and sales KPI cards
- Warehouse and category breakdowns
- Inventory trends and top-selling products
- Supplier performance analysis
- Low-stock alerts
- Category and warehouse filters

## Key Findings

- Educational toys generated the highest sales.
- Some warehouses had excess stock while others faced shortages.
- Fast-selling products needed frequent reordering.
- Higher-rated products tended to perform better in sales.

## Recommendations

- Restock low-inventory products and transfer excess stock between warehouses.
- Add automated reorder alerts and demand forecasting.
- Focus promotions on highly rated products.
- Improve supplier coordination and warehouse distribution.

## Tools

- Microsoft Power BI
- Retail inventory and sales data
